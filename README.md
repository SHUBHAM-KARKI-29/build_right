# build_right

AI-Assisted Software Development & QA Platform

## Overview

build_right is a full-stack web application that assists developers and QA engineers in converting software requirements into structured development and testing artifacts.

## Planned Technology Stack

* React
* Java
* Spring Boot
* PostgreSQL
* REST APIs
* JWT
* LLM API
* JUnit
* Playwright
* GitHub Actions

## Planned Features

* User authentication
* Project management
* Requirement management
* AI-generated user stories
* AI-generated test cases
* Test execution
* Bug tracking
* AI-assisted bug analysis
* Test reports
* Automated testing
* CI/CD
