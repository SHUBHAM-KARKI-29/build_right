# build_right

## Project Description

build_right is an AI-assisted software development and QA platform that helps developers and QA engineers convert software requirements into structured user stories, acceptance criteria, test cases, and bug-analysis suggestions.

The platform combines conventional software engineering with AI-assisted workflows.

## Main Goal

The goal is to build a realistic full-stack application that demonstrates:

* Frontend development
* Backend development
* REST API development
* Database design
* Authentication and authorization
* AI API integration
* Software testing
* Test automation
* CI/CD
* Deployment

## Main Workflow

User creates a project → adds a software requirement → AI analyzes the requirement → user reviews generated user stories and test cases → test cases are executed → failures can be recorded as bugs → AI can assist with bug analysis.

## Target Users

* Developers
* QA engineers
* Software engineering teams
